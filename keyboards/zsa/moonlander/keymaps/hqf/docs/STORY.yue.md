# 我為呢隻鍵盤做嘅所有嘢

我係 Olivier Pons,一個開發者,成日都打緊 code、法文、英文,而家仲加埋語音。呢個鍵位配置唔係落載返嚟嘅現成佈局——係我用咗好多年,一個 commit 一個 commit 噉砌出嚟,務求同我做嘢嘅方式完全夾得埋,喺 Linux 度,用 AZERTY 佈局。呢一頁講嘅係完整嘅故仔:點解佢會存在,同埋佢係點樣行到今日呢一步。

## 問題喺邊度

AZERTY 係為打字機設計嘅,唔係為程式員設計。方括號同運算符都收埋喺唔方便嘅組合鍵後面,成日喺法文同 code 之間切嚟切去,搞到成日都好唔順滑。與其同個佈局頂硬上,我不如喺佈局周圍砌多幾層。

## 每一層做乜嘢

- **L0**:基本 AZERTY 層,同我對手已經識嘅嘢好接近。
- **L1**:程式員需要嘅所有符號,唔使離開主行都攞到。
- **L2**:數字鍵盤同法文口音符號。
- **L3**:複製/貼上同各操作系統專屬快捷鍵,因為 Linux、Windows 同 macOS 從來都唔一致。
- **L4/L5**:RGB 燈光同音效,唔使望都知自己喺邊一層。
- **L6**:將個鍵盤變成遊戲手掣。

## 令個螢幕保持清醒

好早期我就加咗一個滑鼠抖動嘅巨集(`M_JIG_ON` / `M_JIGOFF`):游標每 800 毫秒喺一個細方格入面自己郁一郁,等部機喺長時間通話或者長時間閱讀期間唔會鎖屏或者入睡眠。一個掣開,一個掣關。

## 將鍵盤變成手掣

第六層純粹係為遊戲而設:喺一個掣度用 tap-dance 就可以切換到呢一層,連發(Rapid Fire)巨集會按一個間隔重複一個掣或者滑鼠掣,呢個間隔可以直接喺鍵盤度即時加快或者放慢,唔使重新編譯設定。

## 唔使望都有嘅回饋

按層分嘅 RGB 燈,加埋一大堆 QMK 音效——包括一種「咔嗒」聲嘅打字提示音——等我唔使望鍵盤都知自己而家喺邊個模式。呢個細節,慳返好多「等陣,我而家喺邊一層」嘅困惑。

## 唔使再諗嘅快捷鍵

視窗管理器嘅組合鍵(Ctrl+Alt+方括號、Ctrl+Alt+Z)、喺 Linux、Windows、macOS 都一樣行為嘅複製/貼上、HTML 標籤自動完成、幫我每日打幾十次嘅嘢準備嘅簽名巨集——一個跟一個,呢啲嘢已經唔再係我需要諗嘅嘢。

## 跟得上 QMK 嘅步伐

QMK 會隨住時間淘汰舊嘅按鍵代碼。當 `RGB_*` 同滑鼠按鍵代碼俾 `RM_*`/`MS_*` 取代咗,我揀咗將成個鍵位配置都遷移過去,而唔係由佢喺舊接口度慢慢腐爛。

## 俾佢一把聲

最新加入嘅一部分:Ctrl+Alt+K 用嚟切換 [opons-voxd](https://github.com/olivierpons/opons-voxd),呢個係我另外開發嘅開源語音聽寫工具。呢個係呢塊鍵盤上第一個唔只係郁文字、而係開始「聆聽」嘅掣。

## 點解要分享呢啲

冇人應該原封不動咁抄呢個——每個人隻手同做嘢方式都唔同。但係呢個諗法——用分層去處理符號、系統快捷鍵、回饋、巨集,同埋而家嘅語音——或者可以幫第二個人慳返我用咗好多年先行到嘅路。完整嘅 keymap 同編譯指示就喺上一層資料夾,[keymap 嘅 README](../README.md) 入面。
