# நான் என் Moonlander-ஐ எப்படி பயன்படுத்துகிறேன்

நான் Olivier Pons, ஒரு டெவலப்பர், நாள் முழுவதும் கோட், பிரெஞ்சு, ஆங்கிலம், இப்போது குரலையும் தட்டச்சு செய்கிறேன். இந்த keymap பதிவிறக்கம் செய்யப்பட்ட வடிவமைப்பு அல்ல — இது என் வேலை செய்யும் முறைக்கு சரியாகப் பொருந்தும் வகையில், Linux-இல், AZERTY-இல், பல ஆண்டுகால சிறு மாற்றங்களால் உருவானது.

## சிக்கல்

AZERTY தட்டச்சு இயந்திரங்களுக்காக வடிவமைக்கப்பட்டது, புரோகிராமர்களுக்கு அல்ல. அடைப்புக்குறிகளும் ஆபரேட்டர்களும் சங்கடமான சேர்க்கைகளுக்குப் பின்னால் மறைந்திருக்கின்றன, நாள் முழுவதும் பிரெஞ்சுக்கும் கோடிற்கும் இடையே மாறுவது தொடர்ந்த உராய்வை உருவாக்குகிறது. வடிவமைப்புடன் போராடுவதற்குப் பதிலாக, நான் அதைச் சுற்றி லேயர்களை உருவாக்கினேன்.

## லேயர்கள் என்ன செய்கின்றன

- **L0**: அடிப்படை AZERTY, என் கைகள் ஏற்கெனவே அறிந்ததற்கு நெருக்கமானது.
- **L1**: ஹோம் வரிசையை விட்டு விலகாமல், ஒரு புரோகிராமருக்குத் தேவையான ஒவ்வொரு குறியீடும்.
- **L2**: எண் தட்டு மற்றும் பிரெஞ்சு உச்சரிப்புக் குறியீடு எழுத்துக்கள்.
- **L3**: நகல்/ஒட்டு மற்றும் OS-குறிப்பிட்ட குறுக்குவழிகள், ஏனெனில் Linux, Windows மற்றும் macOS ஒருபோதும் ஒத்துப்போவதில்லை.
- **L4/L5**: RGB விளக்கு மற்றும் ஒலி, பார்க்காமலேயே நான் எந்த லேயரில் இருக்கிறேன் என்பதை அறிய.
- **L6**: விசைப்பலகையை கேமிங் கன்ட்ரோலராக மாற்றுகிறது, ரேபிட்-ஃபயர் மேக்ரோக்களுடன்.

## மேக்ரோக்களும் குரலும்

கையொப்பங்கள், மீண்டும் மீண்டும் வரும் வாக்கியங்கள், விண்டோ-மேனேஜர் குறுக்குவழிகள் — இப்போது எல்லாம் ஒரே விசை அழுத்தத்தில். சமீபத்தில், Ctrl+Alt+K [opons-voxd](https://github.com/olivierpons/opons-voxd) ஐ மாற்றுகிறது, நானே உருவாக்கிய ஒரு திறந்த மூல குரல் கட்டளை கருவி, எந்த மெனுவையும் தொடாமல் தட்டச்சிலிருந்து பேசுவதற்கு மாற உதவுகிறது.

## நான் ஏன் இதைப் பகிர்கிறேன்

யாரும் இதை அப்படியே நகலெடுக்கக் கூடாது — ஒவ்வொருவரின் கைகளும் வேலை செய்யும் முறையும் வேறுபட்டவை. ஆனால் இந்த யோசனை — குறியீடுகளுக்கான லேயர்கள், OS குறுக்குவழிகள், பின்னூட்டம், மேக்ரோக்கள், இப்போது குரல் — நான் இங்கு வர எடுத்த ஆண்டுகளை வேறொருவருக்குச் சேமிக்கக்கூடும். முழுமையான keymap இதே கோப்புறையில் உள்ளது.
