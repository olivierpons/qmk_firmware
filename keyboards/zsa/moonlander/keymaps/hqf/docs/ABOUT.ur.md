# میں اپنا Moonlander کیسے استعمال کرتا ہوں

میں اولیویے پونس ہوں، ایک ڈویلپر، اور دن بھر کوڈ، فرانسیسی، انگریزی، اور اب آواز بھی ٹائپ کرتا ہوں۔ یہ کی میپ کوئی ڈاؤن لوڈ کیا ہوا لے آؤٹ نہیں ہے — یہ برسوں کی چھوٹی چھوٹی تبدیلیوں سے بنا ہے، تاکہ یہ بالکل میرے کام کرنے کے انداز سے میل کھائے، Linux پر، AZERTY میں۔

## مسئلہ

AZERTY ٹائپ رائٹرز کے لیے بنایا گیا تھا، پروگرامرز کے لیے نہیں۔ بریکٹس اور آپریٹرز غیر آرام دہ ترکیبوں کے پیچھے چھپے ہوتے ہیں، اور دن بھر فرانسیسی اور کوڈ کے درمیان بدلتے رہنا مسلسل رگڑ پیدا کرتا ہے۔ لے آؤٹ سے لڑنے کے بجائے، میں نے اس کے گرد پرتیں بنائیں۔

## پرتیں کیا کرتی ہیں

- **L0**: بنیادی AZERTY، جو میرے ہاتھ پہلے سے جانتے ہیں اس کے قریب۔
- **L1**: ایک پروگرامر کو درکار ہر علامت، ہوم رو چھوڑے بغیر۔
- **L2**: نمبر پیڈ اور فرانسیسی لہجاتی حروف۔
- **L3**: کاپی/پیسٹ اور OS کے مخصوص شارٹ کٹس، کیونکہ Linux، Windows اور macOS کبھی متفق نہیں ہوتے۔
- **L4/L5**: RGB روشنی اور آواز، تاکہ بغیر دیکھے پتہ چلے میں کس پرت پر ہوں۔
- **L6**: کی بورڈ کو گیمنگ کنٹرولر میں بدل دیتا ہے، ریپڈ فائر میکروز کے ساتھ۔

## میکروز اور آواز

دستخط، بار بار آنے والے جملے، ونڈو مینیجر شارٹ کٹس — اب سب ایک ہی کی پریس میں۔ حال ہی میں، Ctrl+Alt+K [opons-voxd](https://github.com/olivierpons/opons-voxd) کو ٹوگل کرتا ہے، ایک اوپن سورس وائس ڈکٹیشن ٹول جو میں نے خود بنایا، تاکہ بغیر کسی مینیو کو چھوئے ٹائپنگ سے بولنے پر جا سکوں۔

## میں یہ کیوں شیئر کر رہا ہوں

کسی کو بھی اسے جوں کا توں کاپی نہیں کرنا چاہیے — ہر کسی کے ہاتھ اور کام کرنے کا انداز مختلف ہے۔ لیکن یہ خیال — علامتوں کے لیے پرتیں، OS شارٹ کٹس، فیڈبیک، میکروز، اور اب آواز — کسی اور کے وہ سال بچا سکتا ہے جو مجھے یہاں تک پہنچنے میں لگے۔ مکمل کی میپ اسی فولڈر میں موجود ہے۔
