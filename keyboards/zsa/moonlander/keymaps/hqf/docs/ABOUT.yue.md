# 我點樣用我隻 Moonlander

我係 Olivier Pons,一個開發者,成日都打緊 code、法文、英文,而家仲加埋語音。呢個鍵位配置唔係落載返嚟嘅現成佈局——係我用咗好多年,一點一點噉調校出嚟,務求同我做嘢嘅方式完全夾得埋,喺 Linux 度,用 AZERTY 佈局。

## 問題喺邊度

AZERTY 係為打字機設計嘅,唔係為程式員設計。方括號同運算符都收埋喺唔方便嘅組合鍵後面,成日喺法文同 code 之間切嚟切去,搞到成日都好唔順滑。與其同個佈局頂硬上,我不如喺佈局周圍砌多幾層。

## 每一層做乜嘢

- **L0**:基本 AZERTY 層,同我對手已經識嘅嘢好接近。
- **L1**:程式員需要嘅所有符號,唔使離開主行都攞到。
- **L2**:數字鍵盤同法文口音符號。
- **L3**:複製/貼上同各操作系統專屬快捷鍵,因為 Linux、Windows 同 macOS 從來都唔一致。
- **L4/L5**:RGB 燈光同音效,唔使望都知自己喺邊一層。
- **L6**:將個鍵盤變成遊戲手掣,仲有連發巨集。

## 巨集同語音

簽名、成日重複嘅句子、視窗管理器快捷鍵——而家一個掣就搞掂。最近,Ctrl+Alt+K 可以切換 [opons-voxd](https://github.com/olivierpons/opons-voxd),一個我自己開發嘅開源語音聽寫工具,等我唔使掂任何選單都可以由打字轉做講嘢。

## 點解要分享呢啲

冇人應該原封不動咁抄呢個——每個人隻手同做嘢方式都唔同。但係呢個諗法——用分層去處理符號、系統快捷鍵、回饋、巨集,同埋而家嘅語音——或者可以幫第二個人慳返我用咗好多年先行到嘅路。完整嘅 keymap 就喺同一個資料夾入面。
