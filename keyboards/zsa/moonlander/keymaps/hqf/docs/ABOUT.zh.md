# 我如何使用我的 Moonlander 键盘

我是 Olivier Pons,一名开发者,每天都在打代码、法语、英语,现在还加上语音。这个键位布局不是下载来的现成方案——它是多年来一点点调整的结果,只为完全贴合我的工作方式:在 Linux 上,使用 AZERTY 布局。

## 问题所在

AZERTY 是为打字机设计的,不是为程序员设计的。方括号和运算符都藏在别扭的组合键后面,整天在法语和代码之间切换会带来持续的摩擦。与其与布局对抗,我选择在它周围搭建层(layer)。

## 各层的作用

- **L0**:基础 AZERTY 层,接近我双手已经熟悉的布局。
- **L1**:程序员需要的所有符号,无需离开主行。
- **L2**:数字键盘和法语重音字符。
- **L3**:复制/粘贴以及各操作系统专属快捷键,因为 Linux、Windows 和 macOS 从不一致。
- **L4/L5**:RGB 灯光和音效,让我不用低头就知道自己在哪一层。
- **L6**:把键盘变成游戏手柄,带有连发宏。

## 宏与语音

签名、常用短语、窗口管理器快捷键——现在都只需按一个键。最近,Ctrl+Alt+K 可以切换 [opons-voxd](https://github.com/olivierpons/opons-voxd),这是我开发的一款开源语音听写工具,让我无需碰任何菜单,就能从打字切换到说话。

## 为什么要分享这些

没有人应该原样照搬——每个人的手和工作方式都不同。但这个思路——用分层来处理符号、系统快捷键、反馈、宏,以及现在的语音——也许能为别人节省我花了多年才走到这一步的时间。完整的键位配置就在同一个文件夹里。
