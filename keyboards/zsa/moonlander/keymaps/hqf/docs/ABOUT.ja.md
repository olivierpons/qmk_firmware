# 私が Moonlander をどう使っているか

私は Olivier Pons、開発者です。一日中コード、フランス語、英語、そして今は音声も入力しています。このキーマップはダウンロードしてきたレイアウトではなく、Linux 上で AZERTY を使う自分の仕事のやり方に完全に合わせるため、何年もかけて少しずつ調整してきた結果です。

## 問題点

AZERTY はタイプライター用に設計されたもので、プログラマー向けではありません。括弧や演算子は使いにくい組み合わせの奥に隠れていて、一日中フランス語とコードを行き来すると常に摩擦が生まれます。レイアウトと戦う代わりに、私はその周りにレイヤーを構築しました。

## 各レイヤーの役割

- **L0**:ベースの AZERTY。すでに手が覚えているものに近い状態。
- **L1**:プログラマーに必要なすべての記号を、ホームポジションを離れずに。
- **L2**:テンキーとフランス語のアクセント記号付き文字。
- **L3**:コピー/ペーストと OS 固有のショートカット。Linux、Windows、macOS は決して一致しないので。
- **L4/L5**:RGB ライティングとサウンド。見なくてもどのレイヤーにいるか分かる。
- **L6**:キーボードをゲームコントローラーに変え、連射マクロを追加。

## マクロと音声

署名、繰り返し使うフレーズ、ウィンドウマネージャーのショートカット — すべて今ではキー一つで済みます。最近では、Ctrl+Alt+K で [opons-voxd](https://github.com/olivierpons/opons-voxd) を切り替えられます。これは私が作ったオープンソースの音声入力ツールで、メニューに触れることなくタイピングから発話に切り替えられます。

## なぜこれを共有するのか

誰もこれをそのままコピーすべきではありません — 手も仕事の仕方も人それぞれです。ただ、記号のためのレイヤー、OS のショートカット、フィードバック、マクロ、そして今は音声というアイデアは、私がここに至るまでにかかった年月を誰かの分だけ節約できるかもしれません。完全なキーマップはこの同じフォルダにあります。
